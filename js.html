JavaScript Basics

JavaScript makes your pages interactive. It's the only language that runs directly in the browser — and it's what brings HTML and CSS to life.

01 What is JavaScript?

JavaScript (JS) is a programming language that runs in the browser. It makes pages interactive and dynamic.

You add JavaScript to your HTML page like this:

Linking JS to HTML
<script src="script.js"></script>

02 Variables

Variables store data so you can use it later. In modern JavaScript, we use let and const.

Declaring Variables
const siteName = "DevAcademy";
let score = 0;
score = 10;

03 Data Types

JavaScript works with different kinds of data.

Common Data Types
const name = "Sarah";
const age = 21;
const isReady = true;
const colors = ["red", "blue"];
const user = { name: "Sarah", age: 21 };

04 Functions

A function is a reusable block of code.

Defining & Calling Functions
function greet(name) {
  console.log("Hello, " + name + "!");
}

greet("Alex");

05 DOM Manipulation

The DOM is how JavaScript interacts with the HTML on the page.

Selecting & Changing Elements
const title = document.getElementById("main-title");
title.textContent = "Welcome!";
title.style.color = "teal";

06 Events & Event Listeners

Events happen when a user clicks, types, or interacts with the page.

Adding Event Listeners
const btn = document.getElementById("my-button");
btn.addEventListener("click", () => {
  alert("Button was clicked!");
});

07 Conditionals & Loops

Use if/else for decisions and loops for repetition.

if / else
const score = 85;

if (score >= 90) {
  console.log("Grade: A");
} else {
  console.log("Grade: B");
}
for loop
const courses = ["HTML", "CSS", "JavaScript"];
for (let i = 0; i < courses.length; i++) {
  console.log(courses[i]);
}

📝 Quick Recap

  • JavaScript runs in the browser and makes pages interactive
  • Use let and const to store data
  • Functions are reusable blocks of code
  • The DOM lets you access and modify HTML
  • Event listeners help you respond to user actions
  • if/else and loops help your code make decisions and repeat tasks
