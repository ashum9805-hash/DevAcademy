JavaScript Basics

JavaScript makes your pages interactive. It's the only language that runs directly in the browser — and it's what brings HTML and CSS to life.

01 What is JavaScript?

JavaScript (JS) is a programming language that runs in the browser. While HTML structures content and CSS styles it, JavaScript makes things happen — buttons respond to clicks, pages update without reloading, animations play.

You add JavaScript to your HTML page like this:

Linking JS to HTML
<!-- Always place this just before the closing </body> tag -->
<script src="script.js"></script>
💡 Placing the <script> tag at the bottom of the body means the HTML loads first. If you put it in the <head>, the JS might try to run before the HTML elements exist.

02 Variables

Variables store data so you can use it later. In modern JavaScript, we use let and const.

Declaring Variables
// const = value that won't change
const siteName = "DevAcademy";
const year = 2026;

// let = value that can change later
let score = 0;
score = 10; // this is fine

// var = old way, avoid using it
var oldStyle = "not recommended";
KeywordCan be changed?When to use
constNoMost of the time — names, fixed values
letYesCounters, scores, things that update
varYesAvoid — old, causes bugs

03 Data Types

JavaScript works with different kinds of data. Here are the ones you'll see most:

Common Data Types
const name    = "Sarah";        // String (text)
const age     = 21;             // Number
const isReady = true;           // Boolean (true or false)
const colors  = ["red", "blue"]; // Array (a list)
const user    = {               // Object (key-value pairs)
  name: "Sarah",
  age: 21
};
💡 To check what type something is, use typeof:
typeof "hello" → "string"  |  typeof 42 → "number"

04 Functions

A function is a reusable block of code. You define it once, then call it whenever you need it.

Defining & Calling Functions
// Define the function
function greet(name) {
  console.log("Hello, " + name + "!");
}

// Call the function
greet("Alex");   // prints: Hello, Alex!
greet("Sarah");  // prints: Hello, Sarah!

// Arrow function (modern, shorter syntax)
const add = (a, b) => {
  return a + b;
};

console.log(add(3, 5)); // prints: 8

05 DOM Manipulation

The DOM (Document Object Model) is how JavaScript sees and interacts with your HTML. You can select elements, change their content, or update their styles — all without reloading the page!

Selecting & Changing Elements
// Select an element by its ID
const title = document.getElementById("main-title");

// Select by class name (returns a list)
const cards = document.querySelectorAll(".card");

// Change text content
title.textContent = "Welcome to DevAcademy!";

// Change a CSS style
title.style.color = "teal";

// Add or remove a CSS class
title.classList.add("highlight");
title.classList.remove("highlight");
title.classList.toggle("highlight"); // switches on/off

06 Events & Event Listeners

Events are things that happen in the browser — a click, a keypress, a hover. You can tell JavaScript to listen for these and run code when they happen.

Adding Event Listeners
const btn = document.getElementById("my-button");

// When the button is clicked, run this function
btn.addEventListener("click", () => {
  alert("Button was clicked!");
});

// Common event types:
// "click"      → mouse click
// "mouseover"  → mouse hovers over element
// "keydown"    → keyboard key is pressed
// "submit"     → form is submitted
// "DOMContentLoaded" → page has fully loaded

07 Conditionals & Loops

Use if/else to make decisions, and loops to repeat actions.

if / else
const score = 85;

if (score >= 90) {
  console.log("Grade: A");
} else if (score >= 75) {
  console.log("Grade: B");  // this runs
} else {
  console.log("Grade: C");
}
for loop
const courses = ["HTML", "CSS", "JavaScript"];

for (let i = 0; i < courses.length; i++) {
  console.log(courses[i]);
  // Prints: HTML, CSS, JavaScript (one per line)
}

📝 Quick Recap

  • JavaScript runs in the browser and makes pages interactive
  • Use let and const to store data in variables
  • Functions are reusable blocks of code
  • The DOM lets you access and modify HTML elements
  • Event listeners let you respond to user actions
  • if/else makes decisions, loops repeat actions
