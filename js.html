JavaScript Basics

JavaScript adds real behavior to web pages. It lets you react to clicks, change content, validate forms, and make pages feel alive.

01 What is JavaScript?

JavaScript is a programming language used to make web pages interactive. While HTML structures content and CSS styles it, JavaScript gives the page logic and behavior.

It can do things like update text, respond to button clicks, validate form input, animate elements, and communicate with servers. JavaScript runs in the browser and is one of the core tools of modern web development.

If HTML is the skeleton and CSS is the paint, JavaScript is the engine that makes the page respond.

02 JavaScript syntax

JavaScript uses statements, variables, operators, and functions. A script is usually stored in a file like script.js or written directly inside a page using <script>.

A simple script
const greeting = 'Hello, DevAcademy!';
console.log(greeting);

Variables hold values. const is used for values that should not be reassigned, while let is used for values that may change.

Variable examples
const username = 'Sam';
let score = 0;
score = 1;

03 Data types

JavaScript has several basic data types:

  • string — text such as 'hello'
  • number — numeric values like 42 or 3.14
  • boolean — true or false
  • null — explicitly empty value
  • undefined — value has not been assigned
Examples
const userName = 'Ava';
const age = 16;
const isLoggedIn = true;

Knowing the basic types helps when working with conditions, loops, and user input.

04 Operators and conditions

JavaScript uses operators to compare and calculate values. Common operators include +, -, *, /, and comparison operators like ===, >, and <.

If/else example
const score = 80;

if (score >= 70) {
  console.log('Pass');
} else {
  console.log('Try again');
}

Conditionals let the script choose different actions depending on a condition. They are essential for logic such as checking a form before submitting it or showing a hidden element after a click.

05 Functions

A function is a reusable block of code. Functions help avoid repetition and make scripts easier to organize.

Function example
function greet(name) {
  return `Hello, ${name}!`;
}

console.log(greet('Kaleab'));

Functions can accept parameters, perform work, and return a result. They are used for tasks like validating data, generating outputs, and responding to user actions.

06 DOM manipulation

The Document Object Model (DOM) is the browser's structured representation of the page. JavaScript can access and change elements in the DOM to update text, hide content, and add interactivity.

Changing content in the DOM
const heading = document.querySelector('h1');
heading.textContent = 'Welcome to DevAcademy!';

Common DOM methods include:

  • document.querySelector() selects the first matching element
  • document.querySelectorAll() selects all matching elements
  • element.textContent gets or updates text
  • element.classList.add() adds a CSS class

This is the foundation of interactive sites: click a button, update the DOM, and show new content or styling.

07 Event listeners

Users interact with a page by clicking buttons, typing into forms, scrolling, and more. JavaScript listens for those events and responds to them.

Button click example
const button = document.querySelector('button');

button.addEventListener('click', () => {
  alert('Button clicked!');
});

The addEventListener() method is one of the most important JavaScript features. It allows your code to react to actions like clicks, key presses, and form submissions.

08 Arrays and loops

An array stores a list of values. A loop repeats code as many times as needed.

Array and for loop
const fruits = ['apple', 'banana', 'orange'];

for (let i = 0; i < fruits.length; i++) {
  console.log(fruits[i]);
}

Arrays are useful for lists like product names, scores, or quiz questions. Loops are used to iterate through data and perform the same action on each item.

09 Form validation

JavaScript can prevent invalid form data before it is sent. This is especially useful for checking required fields, minimum password length, or email format.

Simple validation
const password = 'abc';

if (password.length < 6) {
  console.log('Password must be at least 6 characters.');
}

Client-side validation improves the user experience, but it should not replace server-side validation for security and data integrity.

JavaScript checklist

  • Use variables to store values.
  • Write conditions to make choices in your code.
  • Use functions to organize and reuse logic.
  • Update the DOM to show new content and states.
  • Listen for user events like clicks and form submission.
  • Use arrays and loops to process collections of data.
