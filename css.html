CSS Basics

CSS is what makes websites look good. It controls colors, fonts, spacing, layouts, and even animations.

01 What is CSS?

CSS stands for Cascading Style Sheets. While HTML builds the structure of a page, CSS controls how it looks. Think of HTML as the walls of a house and CSS as the paint, furniture, and decoration.

You link a CSS file to your HTML page like this:

Linking CSS to HTML
<head>
  <link rel="stylesheet" href="style.css">
</head>

02 Selectors & Properties

CSS works by selecting an HTML element, then applying properties to it. The basic syntax looks like this:

CSS Syntax
selector {
  property: value;
}

Here are the 3 most common types of selectors:

Selector Targets Example
element All tags of that type p { color: gray; }
.class Elements with that class .card { padding: 20px; }
#id One specific element #header { font-size: 2rem; }

03 Colors, Fonts & Spacing

These are the properties you'll use most as a beginner. They cover the look and feel of almost everything.

Common Properties
p {
  /* Text */
  color: #333333;          /* text color */
  font-size: 18px;         /* text size */
  font-family: sans-serif; /* font style */
  font-weight: bold;       /* bold text */
  text-align: center;      /* align text */

  /* Spacing */
  margin: 20px;            /* space OUTSIDE the element */
  padding: 10px;           /* space INSIDE the element */

  /* Box */
  background-color: teal;  /* background color */
  border: 2px solid black; /* border around element */
  border-radius: 8px;      /* rounded corners */
}
💡 margin vs padding: Margin pushes things away from the outside. Padding adds breathing room on the inside. Imagine a picture frame — padding is the white mat inside, margin is the gap between the frame and the wall.

04 The Box Model

Every HTML element is treated as a box. That box has 4 layers, from inside to outside:

Margin
Border
Padding
Content
Box Model in CSS
.box {
  width: 200px;         /* content width */
  padding: 20px;        /* space inside */
  border: 3px solid;    /* the border line */
  margin: 30px;         /* space outside */
}

05 Flexbox Layout

Flexbox is the easiest way to arrange elements side by side or control spacing between them. You apply it to the parent container.

Flexbox Example
.container {
  display: flex;
  justify-content: center;  /* horizontal alignment */
  align-items: center;      /* vertical alignment */
  gap: 20px;                /* space between children */
}

Common justify-content values:

ValueWhat it does
flex-startAlign to the left (default)
flex-endAlign to the right
centerCenter everything
space-betweenSpread items out, no gaps at edges
space-aroundEqual space around each item

06 Hover Effects & Transitions

The :hover pseudo-class lets you style an element when the user hovers over it. Pair it with transition to make the change smooth.

Hover + Transition
button {
  background: lightcoral;
  transition: background 0.3s, transform 0.3s;
}

button:hover {
  background: teal;
  transform: translateY(-5px); /* moves up 5px */
}
💡 transition goes on the original element, not the hover state. That way the animation plays both when entering AND leaving the hover.

📝 Quick Recap

  • CSS selects HTML elements and applies styles to them
  • Use classes (.name) for reusable styles, IDs (#name) for unique ones
  • margin = space outside, padding = space inside
  • Every element is a box with content, padding, border, and margin
  • Flexbox makes layouts easy — apply it to the parent container
  • Use transition to make hover effects smooth
