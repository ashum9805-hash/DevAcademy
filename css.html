CSS Basics

CSS is what makes the structure on a page look polished and intentional. It handles color, spacing, layout, typography, and interactive states.

01 What is CSS?

CSS (Cascading Style Sheets) is the language that controls the appearance of HTML content. HTML gives the page structure, while CSS decides how that structure looks: colors, fonts, spacing, layout, and visual effects.

Without CSS, a website would be plain, unstyled text and boxes. CSS allows designers and developers to build visually engaging interfaces while keeping the code readable and reusable.

A useful rule of thumb: HTML gives meaning, CSS gives style. JavaScript gives behavior.

02 CSS syntax

CSS follows a simple pattern: a selector chooses the element to style, and a declaration block sets properties and values.

Basic CSS rule
h1 {
  color: #2a7ae0;
  font-size: 2rem;
  text-align: center;
}

In this example, h1 is the selector. The declarations inside the curly braces set the values, and each declaration ends with a semicolon. The rule is applied to every <h1> element on the page.

Common property-value pairs include color: red;, background-color: #f4f4f4;, and margin: 20px;.

03 Selectors and specificity

Selectors tell CSS which elements to target. The simplest selector is an element selector such as p, h1, or button.

Common selectors
p {
  color: #333;
}

.card {
  background: white;
}

#hero {
  padding: 3rem;
}

Selectors can be:

  • Element selectors like p
  • Class selectors like .card
  • ID selectors like #hero

When multiple rules apply to the same element, CSS resolves conflicts through specificity. A more specific selector usually wins, for example #id over .class over element.

04 Colors, fonts, and text styling

CSS lets you control the appearance of text with properties like color, font-size, font-weight, line-height, and text-align.

Text styling example
p {
  color: #333333;
  font-size: 1rem;
  line-height: 1.7;
  text-align: left;
}

Colors can be defined by names like red, hex codes like #2a7ae0, or RGB values. Typography is also controlled in CSS using fonts and size rules.

Common text properties include:

  • font-family for the typeface
  • font-size for the size
  • font-weight for boldness
  • text-transform for uppercase/lowercase

05 The box model

Every HTML element is represented as a box. The CSS Box Model explains how width, height, padding, border, and margin work together.

Content

The box model works from the inside out:

  1. Content — the actual text or image
  2. Padding — space inside the border
  3. Border — the visible edge
  4. Margin — space outside the border
Spacing example
.card {
  width: 250px;
  padding: 20px;
  border: 2px solid #d4cec4;
  margin: 16px;
}

Understanding the box model is essential for layout design because it affects how elements take up space on a page.

06 Layout with Flexbox

Flexbox is a layout system designed to arrange items along a row or column with less manual positioning. It is ideal for navbars, card layouts, and centered content.

Flexbox example
.nav {
  display: flex;
  justify-content: space-between;
  align-items: center;
  gap: 1rem;
}

Flexbox properties include:

  • display: flex; creates a flex container
  • justify-content aligns items along the main axis
  • align-items aligns items along the cross axis
  • gap adds spacing between child elements

Flexbox is great for simple, responsive arrangements and is one of the most common layout techniques in front-end work.

07 Responsive design

Responsive design allows a website to adapt to different screen sizes, such as phones, tablets, and laptops. This is commonly done with CSS media queries.

A media query
@media (max-width: 768px) {
  .navbar {
    flex-direction: column;
  }
}

Media queries run different styles depending on the viewport width. They help make layouts more comfortable on smaller screens and ensure content remains readable.

Good responsive design focuses on flexible layouts, readable font sizes, and content that wraps or reorders sensibly instead of overflowing the screen.

08 Pseudo-classes and interactive states

CSS can target interactive states such as hover, focus, and active states so buttons and links feel responsive.

Pseudo-class example
a:hover {
  color: #e05c2a;
  text-decoration: underline;
}

button:focus {
  outline: 2px solid #2a7ae0;
}

The :hover state changes styling when a pointer is over an element. The :focus state helps keyboard users see which control is active. Accessibility-friendly styling makes interfaces easier to navigate for everyone.

CSS checklist

  • Use CSS to control presentation, not structure.
  • Understand the selector hierarchy and specificity rules.
  • Use the box model to manage spacing and sizing.
  • Leverage Flexbox for layout and alignment.
  • Apply media queries to build responsive pages.
  • Style interactive states to make pages feel polished and accessible.
