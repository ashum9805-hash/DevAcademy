About DevAcademy

Learning web development, one step at a time

A beginner-friendly place to explore the building blocks of the web and practice what you learn.

Why DevAcademy exists

DevAcademy is a small educational website designed to make the first steps into web development feel clear and approachable. It introduces the three core front-end technologies—HTML for page structure, CSS for presentation, and JavaScript for interactivity—in one place.

Learners can read short lessons, try code in the browser playground, and check their understanding with a quiz. The goal is to encourage experimentation: start with the basics, make something, and learn by trying.

📚 What you can do here

  • Learn HTML, CSS, and JavaScript through beginner-focused notes.
  • Use the playground to experiment with code and see a live preview.
  • Take a mixed-topic quiz, review your answers, and jump to related notes.
  • Browse at your own pace—no installation or account is required to explore.

📖 The story

DevAcademy began as a Grade 11 group project and grew into a personal project about sharing the fundamentals of web development. It is built with plain HTML, CSS, and JavaScript so learners can explore the same core technologies the site teaches.

The project was created by Kaleab Ashenafi, a Grade 12 student and aspiring web developer. It is an educational learning project, and its lessons are intended as a friendly starting point for further practice.
