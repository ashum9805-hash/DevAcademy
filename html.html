HTML Basics

HTML is the skeleton of every webpage. It tells the browser what content to show — headings, paragraphs, images, links, and more.

01 What is HTML?

HTML stands for HyperText Markup Language. It is not a programming language — it's a markup language, meaning you use it to label and organize content on a page.

Every webpage you visit is built on HTML. When you open a website, your browser reads the HTML file and displays the content based on the tags you used.

Example
<!DOCTYPE html>
<html>
  <head>
    <title>My First Page</title>
  </head>
  <body>
    <h1>Hello World!</h1>
  </body>
</html>

02 HTML Tags & Elements

HTML is made of tags. Most tags come in pairs — an opening tag and a closing tag. The content goes in between.

Syntax
<tagname> content goes here </tagname>

Here are the most common tags you will use:

Tag What it does
<h1> – <h6>Headings (h1 is biggest, h6 is smallest)
<p>A paragraph of text
<a>A clickable link
<img>Displays an image
<ul> / <ol>Unordered / ordered list
<li>A list item
<div>A container / box for grouping elements
<span>Inline container for small pieces of text

03 Attributes

Attributes give extra information to a tag. They go inside the opening tag like this:

Example
<!-- A link with an href attribute -->
<a href="https://google.com">Visit Google</a>

<!-- An image with src and alt attributes -->
<img src="photo.jpg" alt="A photo of a cat">
💡 Tip: Always add an alt attribute to images. It describes the image for visually impaired users and helps with SEO.

04 Page Structure

Every HTML page follows a basic structure. Think of it like the bones of a body — everything else hangs on this frame.

Basic Page Structure
<!DOCTYPE html>         <!-- Tells browser this is HTML5 -->
<html lang="en">        <!-- Root element of the page -->

  <head>                <!-- Info about the page (not visible) -->
    <meta charset="UTF-8">
    <title>Page Title</title>
    <link rel="stylesheet" href="style.css">
  </head>

  <body>                <!-- Everything visible goes here -->
    <h1>My Heading</h1>
    <p>My paragraph.</p>
  </body>

</html>

05 Semantic HTML

Semantic tags describe the meaning of content, not just how it looks. They make your code cleaner and easier to understand.

❌ Non-Semantic
<div>
  <div>Logo</div>
  <div>Main content</div>
  <div>Footer text</div>
</div>
✅ Semantic
<body>
  <header>Logo</header>
  <main>Main content</main>
  <footer>Footer text</footer>
</body>

Other semantic tags include: <nav>, <section>, <article>, and <aside>.

📝 Quick Recap

  • HTML is a markup language — it structures content
  • Tags come in pairs: opening and closing
  • Attributes add extra info inside the opening tag
  • Every page needs <!DOCTYPE>, <html>, <head>, and <body>
  • Use semantic tags to write clean, meaningful HTML
