Module 1

HTML Basics

HTML gives web pages their structure and meaning. Learn the elements that organize text, images, links, and forms.

01 What is HTML?

HTML (HyperText Markup Language) is the standard markup language used to describe the structure and meaning of content on a web page. It uses elements—written with tags—to tell a browser what each piece of content represents.

HTML is not a programming language: it describes content rather than providing logic or calculations. CSS controls presentation, while JavaScript can add behavior.

Think of a web page as a house: HTML is the structure and rooms, CSS is the paint and decoration, and JavaScript is the switches and moving parts.

02 The basic document structure

A complete HTML document starts with a doctype declaration, then the root <html> element. The <head> contains page information and linked resources; the <body> contains the content visitors see.

A minimal HTML page
<!doctype html>
<html lang="en">
  <head>
    <meta charset="utf-8">
    <meta name="viewport" content="width=device-width, initial-scale=1">
    <title>My first page</title>
  </head>
  <body>
    <h1>Hello, web!</h1>
    <p>This is my first page.</p>
  </body>
</html>
  • <!doctype html> tells the browser to use modern HTML standards mode.
  • lang="en" identifies the document language for browsers and assistive technology.
  • <meta charset="utf-8"> enables a broad range of characters and symbols.
  • The viewport setting helps the page scale to the device width on phones and tablets.
  • <title> supplies the browser-tab title and a useful page name in search results.

03 Elements, tags, and attributes

An HTML element usually consists of an opening tag, content, and a closing tag. Tags are written inside angle brackets. Some elements, such as <img> and <meta>, are void elements and do not wrap content.

An element with an attribute
<a href="https://example.com">Visit Example</a>

Here, <a> is the tag, the full link is the element, and href is an attribute that provides extra information. Attributes are written in the opening tag, usually as name="value".

Always quote attribute values and use lowercase tag and attribute names for readable, consistent HTML.

04 Headings and text

Use headings to organize the page into a meaningful outline. <h1> is the main heading, followed by nested section headings from <h2> through <h6>. Choose a heading level because of its place in the outline, not just its default size.

A simple content outline
<h1>A Guide to Gardens</h1>
<p>An introduction to growing plants at home.</p>

<h2>Getting started</h2>
<p>Choose a sunny place and healthy soil.</p>

<h3>Choosing a pot</h3>
<p>Make sure it has drainage holes.</p>

Use <p> for paragraphs, <strong> for important content, and <em> for emphasis. These elements communicate meaning, unlike using visual styling alone.

05 Links, images, and lists

Links connect pages and resources. The link text should make sense on its own and describe where it leads.

Links and images
<a href="about.html">Read about our team</a>

<img src="garden.jpg" alt="Red flowers growing in a garden">

The alt text provides an accessible text alternative for an informative image. If an image is purely decorative and adds no information, use an empty alternative: alt="".

Use <ul> for an unordered list, <ol> when order matters, and <li> for each item.

A list of steps
<ol>
  <li>Pick a topic.</li>
  <li>Write a first draft.</li>
  <li>Review and improve it.</li>
</ol>

06 Semantic page structure

Semantic elements describe the purpose of their content. They make page structure easier to understand for people, browsers, and assistive technologies.

A semantic layout
<header>
  <h1>Local Nature Club</h1>
</header>
<nav aria-label="Main navigation">
  <a href="index.html">Home</a>
  <a href="events.html">Events</a>
</nav>
<main>
  <article>
    <h2>Our next event</h2>
    <p>Join us for a community planting day.</p>
  </article>
</main>
<footer>Contact the club for details.</footer>

Common landmarks include <header>, <nav>, <main>, <article>, <section>, and <footer>. Use <div> when no more meaningful element fits, rather than using it for every container.

07 Tables for tabular data

Tables are for information that naturally belongs in rows and columns, such as schedules or comparison data—not for laying out the whole page. Use header cells to identify each column or row.

A small data table
<table>
  <caption>Club meeting schedule</caption>
  <thead>
    <tr><th scope="col">Day</th><th scope="col">Activity</th></tr>
  </thead>
  <tbody>
    <tr><td>Tuesday</td><td>Planting</td></tr>
    <tr><td>Friday</td><td>Garden care</td></tr>
  </tbody>
</table>

08 Forms and labels

Forms collect information from visitors. Connect every input to a visible <label> so its purpose is clear and it can be activated by clicking the label.

A basic form
<form action="/subscribe" method="post">
  <label for="email-address">Email address</label>
  <input id="email-address" name="email" type="email" required>
  <button type="submit">Subscribe</button>
</form>

The for value on the label must match the input's id. The name is the field name submitted with the form. Choose an appropriate input type, such as email, and use built-in attributes like required when they fit.

HTML checklist

  • Start with a valid document structure and set the page language.
  • Use headings in a logical order to outline the content.
  • Choose semantic elements that describe the role of the content.
  • Write descriptive link text and useful image alternatives.
  • Associate form fields with labels, and use tables only for tabular data.
  • Keep structure in HTML; use CSS for visual design and JavaScript for behavior.
